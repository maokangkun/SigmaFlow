# 虚拟病原体环境（Pathenv）设计总览

> 定位：与「虚拟患者」同构的**仿真沙盒 + 智能体训练/评估基准**。
> 覆盖「下到分子、上到群体」的全部尺度，并把每一层都变成智能体可观测、可操作、**可打分**的接口。
> 边界声明（页面与文档常驻）：参数取自教科书/公共卫生量级而非拟合数据，用于教学、训练与相对比较，
> **不能作为临床决策或流行病学预测依据**；每个模块与目录条目都带保真度标注（见 §9）。

---

## 1. 五层结构（补充项落位）

```
L0 分子/基因组层   序列 · 变异 · 基因环境 · 耐药注释 · 抗原表位 · 系统发生
```

## 2. L0 分子/基因组层（`js/patho/genome.js`）

**为什么可以"有基因组"而不存基因组**：不落库真实序列（MB 级），而是**确定性伪基因组**：
`sequence(pathogen, gene) = PRNG(hash(pathogenId + geneId))` 生成等价长度的核苷酸串。
性质：可复现（同 id 恒同序列）、可 diff（变异即"记录差异"）、体积为 0、可被 k-mer/比对算法正常消费。

- **基因图式（gene schema）**：按原型（archetype）给出基因清单——聚合酶/表面糖蛋白/结构蛋白/耐药决定簇/
  毒力因子/可移动元件，每个基因带长度、功能类、必需性、变异容忍度、是否表位密集。
- **变异表示**：`{gene, pos, ref, alt, af, class, effect}`。突变供给率 μ 按原型；选择压来自 L1（药物/免疫）+ L0 适应度代价。
- **突变效应模型** `effect class`：
  - 酶活性/结合口袋 → 对某类药物 `fold-IC50`（可分梯度：低/中/高抗性）
  - 表面抗原 → 对某株抗体 `fold-中和下降`
  - 必需基因错义 → 适应度代价 `w = 1 − c`（决定能否固定）
  - 调控/启动子/拷贝数 → 表达量上调（耐药但不改靶点）
- **基因环境/耐药注释** `resistome`：决定簇目录 + 匹配规则（SNP 目录、获得基因、质粒/整合子携带、外排泵、
  靶点修饰、酶灭活），输出**机制文字 + S/I/R 预测 + 证据强度**。
- **系统发生与溯源** `phylo`：SNP 距离 → 距离矩阵 → UPGMA/NJ-lite → 保守簇；
  `trace` 结合发病时间与地点（含旅行/接触网络）反推传播链与共同来源，输出置信度（真值可查 → 可打分）。
- **演化预测** `forecast`：Wright–Fisher / 竞争 Lotka–Volterra 变体频率投影，
  压力来自药物暴露（MSW 富集）、疫苗免疫（逃逸选择）、传播优势（R0 因子）；
  输出优势株、时间到优势、区间与情景对比。
- **药物匹配** `drugmatch`：基因型 → 表型（合成 fold-change）→ 推荐/不推荐 + 抗性屏障（还需几个突变）
  + 交叉耐药与联合用药的抑制突变策略。
- **疫苗设计** `vaccine`：候选抗原（保守度 × 免疫原性 × 覆盖谱 × 可制造性）→ 平台（灭活/重组蛋白/mRNA/载体/减毒）
  → 免疫动力学（首剂/加强/免疫印迹）→ **覆盖率预测**（对当前与预测变体谱的表位距离）→ 逃逸风险位点清单。

## 3. L1 宿主内层（`js/patho/host.js`）

- **病毒**：靶细胞模型 `T, I, V`；固有免疫 IFN（延迟 4–12h，饱和）；适应性 CD8/抗体（延迟 5–7 天，Hill）；
  抗病毒药作用于 β（入胞）、p（复制）、c（释放）之一。
- **细菌**：Logistic 生长 + 分室（胞外/胞内/生物膜）+ 抗生素 PK（单室，ka/t½/τ）+ PD（Hill Emax vs MIC）+ PAE；
  **双亚群 S/R**（突变率 μ、适应度代价）+ 水平转移（质粒）；MSW 窗口选择性富集。
- **真菌/原虫/结核（胞内）**：在此基础上加"宿主细胞庇护所""药物穿透系数""免疫控制阈值"。
- **免疫**：固有 → 适应性 → 记忆（含免疫抑制、免疫耗竭、免疫印迹）。
- **输出**：载量曲线、组织损伤、症状/发热、免疫效应、**传染性曲线 I(t)**（唯一通往 L3 的耦合出口）。
- 引擎既有 `patient.js` 的 `PATH_LIB`/`pathogenStep()` 作为种子：生物学语义保留（20 种病原体），
  算法换成指数积分器 + 自适应子步长（保证正性与稳定性），病原体目录扩到全集。

## 4. L2 观测层（`js/patho/diag.js`）

| 检测 | 生成规则 | 关键参数 |
| --- | --- | --- |
| 核酸检测 qPCR | `Ct = Ct_max − k·log10(载量) + 噪声`，低于检出限→未检出 | 检出限、效率、抑制物 |
| 抗原快速检测 | 灵敏度随载量 S 曲线（高 Ct 假阴） | 灵敏度/特异度 |
| 培养 + CFU | 泊松采样，受抗生素活性抑制 | 生长时滞、污染率 |
| 药敏 MIC 面板 | 由耐药亚群比例决定折点（S/I/R） | 面板药物、折点表 |
| 血清学 IgM/IgG | 动力学延迟曲线 | 交叉反应 |
| 测序 | 深度控制（100–10⁵ reads）、错误率、变异 AF 检出阈值 | 深度→检出概率、混样稀释 |
| 病原识别 | 读数→k-mer 比对→候选谱丰度 + 置信度 + 污染/背景 | panel 覆盖、背景 flora |
| 病例调查 | 暴露史/接触网络/地理 | 回忆偏倚、漏报 |

**所有"数字"必须经此层产出**（智能体不能直接读内部状态，除非显式"开发者视图"），
这样"推断类任务"才有难度、才能打分。

## 5. L3 群体层（`js/patho/pop.js`）

- 元种群 SEIR：地区 × 年龄分组 × 分室（S/E/I/Is/H/R/D），接触矩阵 + 通勤/旅行流动性。
- 变体株：(传播力 ×, 免疫逃逸 ε, 重症度 σ, 抗原距离)；频率演化由 L0/L1 竞争模型驱动。
- 干预：疫苗（平台/覆盖率/分配/加强）、NPI（口罩/限聚/停课/封控强度）、检测-追踪-隔离（灵敏度·延迟·覆盖率）、
  治疗（药物供应与分配）、旅行限制。
- 监测：**基因组测序采样比例** → 变体频率估计（抽样噪声 + 报告延迟）、`Rt` nowcasting、血清阳性率调查。
- **溢出预警** `spillover`：动物宿主/媒介 + 人兽界面暴露 + 受体兼容性 + 基因屏障距离（与已适应人株的表位/受体差异）
  + 监测灵敏度 → 风险评分与因子分解，输出 watchlist；支持 what-if（提高界面接触→预期爆发规模）。
- 指标：Rt、峰值、住院占用/挤兑时长、累计感染、超额死亡、逃逸事件时间、干预成本-效果前沿。

## 6. L4 试验台与真值评分（`js/patho/trial.js`）

- **场景卡**：病原体 + 宿主与群体参数 + 初始条件 + **真值注册表**（真实耐药型/传播链/变体动力学/最优策略）。
- **协议**：时间表式干预（`t=0 给药 X mg q8h`、`t=3 换药`、`t=5 隔离`、`t=7 采样测序`）+ 采样计划。
- **运行**：N 次重复（随机种子）→ 指标分布与 bootstrap CI；两臂并排对比；CSV/JSON 导出；会话归档可回放。
- **四类任务与打分**：

| 任务类 | 例子 | 评分 |
| --- | --- | --- |
| 推断 | 病原识别、耐药注释、宿主溯源、变体预测 | accuracy / F1 / Brier / 置信区间覆盖率 |
| 控制 | 治疗到清除且不产生耐药；30 天压平曲线 | 是否达标 + 代价（药量/AUC/超额死亡） |
| 设计 | 疫苗抗原与平台选择、监测布局、用药方案 | 覆盖率/成本/鲁棒性 |
| 分析 | 设计对照实验：样本量、对照、混杂控制 | 统计功效 + 是否被混杂欺骗 |

## 7. 病原体目录：从 20 → 全覆盖（`js/patho/catalog.js`）

- **条目字段**：分类学（科属/基因组类型/大小）、传播途径与基本再生数区间、潜伏期、组织趋向、
  致病谱、固有耐药、可用药物类与靶点、疫苗可得性与平台、动物宿主/媒介、BSL 等级、可报告性。
- **原型（archetype）集合**提供全部动力学参数（这套只有约 20 组）：
  病毒 dsDNA / ssRNA+ / ssRNA− / 分段 / 逆转录；细菌 G+ / G− / 胞内 / 结核 / 厌氧 / 孢子；
  真菌（酵母/霉菌/机会性）；原虫（疟原虫/弓形虫/利什曼/贾第虫）；蠕虫（简化）；朊粒（特殊，无核酸）。
- **条目 = archetype 动力学 + 覆盖字段 + 保真度 tier**：
  - `Tier A`：精调参数（流感、SARS-CoV-2、HIV、结核、MRSA、疟原虫…核心 ~30 条）
  - `Tier B`：继承原型默认值并做量级校正（多数细菌/病毒）
  - `Tier C`：仅目录与定性行为（罕见病原体）
- 目标规模：**WHO 人类病原体全集量级（~200 条）**，含细菌/病毒/真菌/原虫/蠕虫/朊粒。

## 11. 工程与性能

- 纯 JS，无新依赖；模块按尺度拆分，进页面懒加载。
- 数值：指数积分器 + 自适应 dt（L1），元种群 ODE 向量化（L3，dt=0.25 天 × 365 天 × 规模 ~10² 维 → 毫秒级）。
- L0 不存序列（种子生成），测序读数按需生成，内存 O(reads)。
- 可复现：`(scenario, seed, protocol)` 唯一决定结果；导出含三者的 JSON 便于复算。
- 测试：Python 桥接/工具清单单测 + Node 直跑纯模块的数值不变量测试（单调性、守恒、边界）。

## 12. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 参数可信度不足被误当预测 | tier 标注 + 常驻声明 + 只允许相对比较结论 + 文档记录参数来源量级 |
| 多尺度耦合产生"看似合理但错误"的因果 | 耦合只走显式接口（I(t)、逃逸系数、耐药 fold-change），UI 与文档把耦合点画出来 |
| 200 病原 × 5 层组合爆炸 | 原型继承 + 惰性求值 + 每层只算激活模块；非激活尺度不消耗算力 |
| Agent 上下文被工具描述挤爆 | 分层 MCP 服务器可单独开关；描述控制在两行内 |

## 13. 待确认决策

1. **目录规模**：~60（核心精调）/ **~200（WHO 人类病原体全集，含真菌·原虫·蠕虫·朊粒）** / 更大（含兽医与植物病原）。
